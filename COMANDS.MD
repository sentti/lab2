# Основные команды Git

## git init
Инициализирует новый локальный репозиторий Git в текущей папке. Создает скрытую папку `.git` где хранится вся история изменений и настройки репозитория.

## git clone
Создает локальную копию удаленного репозитория. Копирует все файлы, историю коммитов и ветки с удаленного сервера на ваш компьютер.

## git add
Добавляет изменения из рабочей директории в индекс (staging area) для подготовки к следующему коммиту. Можно добавлять отдельные файлы или все изменения сразу.

## git commit
Фиксирует изменения, добавленные в индекс, создавая новый коммит в истории репозитория. Каждый коммит имеет уникальный хеш и сообщение, описывающее изменения.

## git push
Отправляет локальные коммиты в удаленный репозиторий. Синхронизирует ваши изменения с сервером (GitHub, GitLab, Bitbucket).

## git pull
Забирает последние изменения из удаленного репозитория и объединяет их с вашей локальной версией. Эта команда эквивалентна последовательному выполнению `git fetch` и `git merge`.

**Примеры использования:**

# Инициализация нового репозитория
git init

# Клонирование удаленного репозитория
git clone https://github.com/user/repository.git

# Добавление файлов в индекс
git add README.md

# Создание коммита
git commit -m "Добавила README"

# Отправка изменений на сервер
git push origin main

# Получение обновлений с сервера
git pull origin main
